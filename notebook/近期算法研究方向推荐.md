# 自进化智能体框架

一个被说烂的命题。

自进化这里主要分`在线持续学习`和 `离线自驱迭代`：

**在线持续学习**：一般采用非参数化系统。强调的是 Agent 在运行过程中与环境实时交互、即时吸收反馈并调整行为策略。典型场景是用户与 Agent 的对话流中产生的偏好信号沉淀及未来复用，或是任务执行失败后的既有prompt自我修正。

**离线自驱迭代（Parametric** **Memory****）**：是更传统也更有规模的进化方式。把 Agent 一段时间内的运行轨迹、成功/失败案例、用户反馈批量收集起来，在离线环境中做数据分析、模型微调或 prompt 蒸馏，最终以一个「新版本」的形式整体替换上线。

# 一点想法

*   **Automated Agent Genetic Evolution (AAGE)**
    

:::
参考GA（遗传算法），将Agent中的Prompt、CoT、MCP Python脚本等定义为“基因”，在模拟沙盒（Harness）中运行多个Agent（上述基因组合），根据任务完成率计算适应度（Fitness），利用LLM执行交叉（Crossover）和变异（Mutation），不断衍生出下一代Agent，只到达成终止条件：

**达到最大迭代次数：** 预先设定的最大进化代数（Generation）已经耗尽。

**适应度阈值满足：** 种群中的最优适应度已达到所要求的误差范围或预设的阈值。

**适应度无显著提升：** 在连续若干代（如 50 代或 100 代）中，最优个体的适应度变化量小于一个极小值（即更新停滞）。

**种群多样性下降：** 种群中个体的基因组合相似度超过设定的阈值，群体已趋于同质化，失去进化多样性。
:::

*   **Online Trajectory-Informed Policy Distillation**
    

:::
以 边际成本下降 为核心优势，追求极致的“高效训练”和“低成本推理”。所以采用的是同一套Harness下 Teacher Model 实时产生轨迹数据，轨迹数据经过进本的预处理和提纯后，快速进行小模型的蒸馏学习。整个学习过程不追求大而全，以夹逼准则完成对单场景的“过拟合”，实现单点的绝对效果优势，并迅速推送模型、部署大模型服务、接入线上agent runtime。
:::
